# Chatbot

## Project Description
This is a Python-based chatbot designed to interact with users and provide automated responses to basic queries. It simulates human-like conversation and helps users get quick information.

## Features
- Interactive conversation  
- Handles basic user queries  
- Provides automated responses  
- Simple and user-friendly interaction  

## Technologies Used
- Python
- pyautogui
- pyperclip
- OpenAI API
